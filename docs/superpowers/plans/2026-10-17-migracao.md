# Minha Cozinha — Implementation Plan

**Goal:** Migrar todas as telas do protótipo mantendo o design e tornando funcionais as operações locais.
**Architecture:** App Router com entradas de servidor, funcionalidades interativas isoladas e contexto React simples. Repositório puro separa os dados da apresentação.
**Tech Stack:** Next.js estável, React, TypeScript, Tailwind 4, Lucide, React Hook Form e Zod.
**Spec:** `docs/superpowers/specs/2026-10-17-migracao-design.md`

## Restrições

Sem backend, autenticação, banco de dados ou serviços externos novos. Preservar CSS, fotos, fontes e comportamento. Não trocar o design por shadcn.

## Pontos de revisão

URLs diretas e voltar/avançar; IDs inexistentes; formulários vazios; armazenamento indisponível/corrompido; controles e filtros em 390px.

## Etapas

- [ ] Configurar Next, PostCSS, TypeScript, lint e scripts; manter CSS original com tokens adicionais.
- [ ] Extrair tipos e demonstração; implementar repositório puro e testar criação/edição/IDs.
- [ ] Extrair componentes visuais sem alterar classes; criar rotas e navegação Next.
- [ ] Implementar contexto com persistência validada, formulários RHF/Zod e upload local.
- [ ] Conectar planejamento, compras e diário; validar filtros, estrelas, checklist e modo cozinha.
- [ ] Executar build, lint, typecheck, testes e checagens de rotas/browser; documentar execução e limites.

Execução incremental nesta sessão, conforme pedido do usuário. Não há necessidade de nova aprovação para a migração já autorizada.
