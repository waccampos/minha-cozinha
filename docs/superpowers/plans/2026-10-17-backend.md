# Backend Implementation Plan

**Goal:** Persistir a cozinha compartilhada no PostgreSQL existente mantendo os componentes.
**Architecture:** schema isolado Prisma; serviços transacionais; DTOs tipados; Server Actions e Route Handlers; armazenamento seguro local.
**Spec:** docs/backend/design.md

## Restrições

Não criar instância PostgreSQL; não tocar schemas externos; não registrar segredos; preservar CSS e estrutura visual; não usar mock como fallback.

## Revisão

Entradas inválidas não gravam; arquivo falso/excessivo não é armazenado; exclusões na busca são obrigatórias; alteração concorrente não perde favoritos/itens; backup só contém minha_cozinha.

- [ ] Testes de regras/limites antes da implementação; configurar Prisma e migration isolada.
- [ ] Implementar repositório e serviço CRUD transacional, snapshot e regras de histórico/agenda/compras.
- [ ] Upload, leitura e coleta de imagens sem referência; testar assinatura, tamanho e caminhos.
- [ ] Busca estruturada/FTS parametrizada com pg_trgm opcional e exclusões estritas.
- [ ] Integrar Server Actions/provider/componentes e estados vazios/erros sem mudar design.
- [ ] Scripts de backup/restauração e instruções LAN/permissões restritas.
- [ ] Executar testes, prisma validate, tipos, lint, build e integração quando DATABASE_URL existir.
